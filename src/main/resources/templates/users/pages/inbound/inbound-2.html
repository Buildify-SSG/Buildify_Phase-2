📘 Thymeleaf 문법 정리

✅ 변수 출력

<span th:text="${user.name}">홍길동</span>
→ 모델에 담긴 user.name 값을 출력

✅ 조건문

<div th:if="${user.admin}">관리자입니다</div>
<div th:unless="${user.admin}">일반 사용자입니다</div>
→ if: 조건 true일 때 / unless: 조건 false일 때

✅ 반복문 (for-each)

<tr th:each="item : ${itemList}">
  <td th:text="${item.name}"></td>
  <td th:text="${item.qty}"></td>
</tr>
→ itemList를 반복해서 출력

✅ 반복문 + 인덱스

<tr th:each="item, stat : ${itemList}">
  <td th:text="${stat.index}"></td>
</tr>
→ stat.index로 인덱스(0부터)를 가져올 수 있음

✅ 링크(URL) 설정

<a th:href="@{/product/detail(id=${product.id})}">상세보기</a>
<img th:src="@{/images/logo.png}" />
→ @{} 사용 시 URL 경로 자동 완성됨

✅ 폼 요소 값 설정

<input type="text" th:value="${user.name}" />
<option th:each="c : ${countries}"
    th:value="${c.code}"
    th:text="${c.name}"
    th:selected="${c.code == user.country}">
</option>
<input type="checkbox" th:checked="${user.admin}" />

✅ fragment (공통 템플릿)

<div th:fragment="header">헤더 내용</div>

<div th:insert="~{fragments :: header}"></div>
→ 공통 레이아웃을 분리하고 포함시킬 때 사용

✅ JS에서 변수 사용

<script>
  let userId = '예시유저ID';
</script>

✅ 클래스/속성 조건부 출력

<li th:class="\${menu} == 'stock' ? 'active' : ''">재고</li>
<input type="checkbox" th:checked="\${user.active}" />

📎 팁 정리

  • \${}: 자바 모델에서 값 꺼낼 때 사용
  • \@{}: URL 매핑 자동 처리
  • \[\[ \]\]: JS, 속성 안에서 값 바인딩
  • th:*: HTML 태그 안에서 속성 치환
