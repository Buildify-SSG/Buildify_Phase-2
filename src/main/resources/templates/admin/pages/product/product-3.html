📌 아이콘 넣는 방법 (feather icons)

<i class="align-middle" data-feather="circle"></i>
※ circle = 아이콘 이름 (예: user, home, settings 등)

📁 templates 디렉토리 구조 예시

📁 templates
└── 📁 admin
    ├── index.html
    ├── sub.html
    └── 📁 inbound
        └── page-1.html

📎 페이지 이동 방법

1. 같은 디렉토리 내 파일 이동 (예: admin/index → admin/sub)

<a th:href="@{/sub}">이동</a>

2. 하위 디렉토리 이동 (예: admin/index → admin/inbound/page-1)

<a th:href="@{/inbound/page-1}">입고 페이지</a>

✅ 추가 참고

  • @{}는 Spring에서 URL 자동 맵핑을 지원
  • 경로 기준은 컨트롤러 매핑 + templates 경로 기준임
  • 서버 재시작 없이도 feather 아이콘은 feather.replace() 한 번 실행되면 적용됨
